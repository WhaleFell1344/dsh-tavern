# MVU 事务按需历史（2026-09-28）

## 实现

`readSettlementBase` 在原生存储中固定不可变 head，返回头部与保留完整 length/绝对下标的内部消息视图。按 64 条取得页面引用，仅解码明确要求的楼层。未加载下标抛出 `MVU_HISTORY_NOT_LOADED`，不伪装成不存在；宿主异步边界负责 ensure。首次写楼层复制该楼层，事务覆盖层优先于历史基线。明确请求完整上下文仍加载全部历史；旧 JSON/JSONL 存档保留原来的工作副本路径。

页面摘要保存 MVU 快照存在标记。查找前一快照时逆序扫描标记，命中后加载该楼层；旧原生页没有标记时只检查选中 swipe 的变量键。稀疏快照长间隔仍需扫描页面元数据，并非所有情况 O(1)。

首次真实浏览器测试 `run-Z16Xme` 暴露了版本交接对整档缓存的隐藏依赖：浏览器落后一版时无法取得变更覆盖，触发完整恢复。因此原生写入现在把变更楼层、布局变化起点随 head CAS 一并发布。重启后也能查最近 64 版增量；覆盖缺失、跨越窗口或不兼容布局仍完整恢复，不能静默遗漏变化。

新原生 MVU 效果保存修改字段的原值，提交前统一校验；同字段并发修改拒绝覆盖，不同字段修改保留。剧情版本、生命周期、swipe、事件身份和持久化 CAS 继续生效。异步加载后再次核对事件，事务结束后的迟到写入不得加入下一次结算。
