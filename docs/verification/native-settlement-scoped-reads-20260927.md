# 原生结算保存点与元数据读取（2026-09-27）

本轮延续 `ce7cd83d` 的万轮基线，处理无需历史正文的整档读取。

## 实现与兼容边界

- `readSettlementCheckpoint` 在原生分页存储直接读目标楼层，以及生命周期、存档版本、时间线分支/版本/操作字段。此前该接口先完整加载再投影。保留旧格式路径，以及旧时间线需迁移时的完整处理路径。
- `bindSession` 新增内部 `stateOnly` 选项，结算调用者绑定后台会话后只需状态，不再重新读取完整故事。默认调用契约不变，写入冲突仍走原有校验和回退。
- 模型流的模板路由、请求日志及世界书日志关联只读取所需元数据；保留兼容模式记录、预设信息和 foregroundFrames。会话别名恢复及旧配置采用仍交回原读取器。
- 结算结束唤醒仅读取会话状态，不再为 sessionId 读取完整 Chat。

没有删除历史、缩短模型的合法上下文、扩大缓存，也没有将部分 Chat 作为完整存档写回。世界书仍可能需要历史 transcript，不能直接替换成截断窗口而改变模板语义。

## 验证

1200 楼层冷存储保存点测试修改前失败（遍历历史页），修改后只读取目标所在页，并校验读取出的存档版本可以成功进行局部 CAS 写入、返回值可独立修改。针对性回归 49 项全部通过，覆盖存储、后台任务、时间线状态、模型请求日志及世界书日志。

首次 E2E 复测 `run-qplPJh` 暴露保存点字段选择遗漏 `_storageRevision`，导致局部 CAS 未命中而回退整档更新。已补齐该字段，并增加真实写入断言后重新验证。该中间版本数据不作为最终结果。
