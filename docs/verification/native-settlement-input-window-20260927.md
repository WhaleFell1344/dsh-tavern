# 结算初始输入窗口（2026-09-27）

## 实现与适用范围

新增内部 `readSettlementInput`，针对原生存档的变量重新结算读取末尾 200 条。使用保留完整 length 与绝对下标的稀疏内部消息视图，已有目标变量、相邻 Helper 内容及头部元数据保持不变。此输入不得用于完整 Chat 写入。

只有以下条件同时满足才采用窗口：配置已采用、存档版本与窗口版本一致、原生时间线无旧正文迁移、世界书准备版本与时间线版本相同、官方 MVU 已启用、窗口内最新待处理目标明确标记 variableRetry，以及目标之前的助手边界已包含在窗口内（或窗口就是完整短历史）。

世界书准备过期、普通新轮次、旧格式/配置、版本异常或 Helper 段跨越窗口边界时保留完整读取。后台任务启动仍通过版本 CAS，冲突后重新读取权威状态；完成及失败的写入仍使用原有存储校验，不直接保存局部输入。

这次并未取消 MVU 工作副本的完整读取。它支持脚本访问任意历史楼层，不能把未加载楼层当成不存在；后续需要把事务草稿改成支持按需读取的修改覆盖层，并确保完整上下文请求与旧楼层写入仍正确。
